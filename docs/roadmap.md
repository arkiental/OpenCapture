# Roadmap

Features of the reference application, in rough priority order. Each one gets a
research log and a behaviour spec before (or while) it is implemented.

| Feature | Status |
|---|---|
| Rectangular Region capture | ✅ v0.1.0 – [spec](behavior/rectangular-region.md) |
| Output options: to clipboard, to file (Save As), auto-save with file-name template (`$Y $M $D $H $N $S #`) | 🟡 Save As / Copy in the result window only |
| Settings (hotkeys, output, include mouse pointer, delay before capture) persisted in an INI next to the exe | ⬜ |
| Capture Panel (floating toolbar) | ⬜ |
| Full Screen capture (active monitor / all monitors) | ⬜ |
| Active Window capture | ⬜ |
| Window / Object capture | ⬜ |
| Freehand Region capture | ⬜ |
| Fixed Region capture | ⬜ |
| Scrolling Window capture | ⬜ |
| Editor (annotate, crop, resize, effects) | ⬜ (current result window is a placeholder) |
| Screen tools (color picker, magnifier, ruler, crosshair) | ⬜ |
| Screen recorder | ⬜ |

Open questions for the Rectangular Region capture are listed in its spec
(multi-monitor and high-DPI behaviour of the reference).
